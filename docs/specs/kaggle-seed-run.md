# Spec T-KG-01: LightGBM seed fits on Kaggle (seeds mode of the runner)

Status: proposed (2026-11-03). Authority: ADR 0006 sections 3.8, 5, 8, H-D6; owner decisions of 2026-11-03 (seeds
on Kaggle; full_v0 rebuilt in Kaggle with the existing runner; writes only to private `astro-triage-*` resources;
each output download needs its own explicit yes). Reversible in < 1 day; the default path is untouched.

## Facts read (not assumed)
- Runner XMatch radius 2.0 arcsec (`run_kaggle.py:400-401`, = `xmatch_full.py:446` default) is the query upper
  bound. `build_dataset` keeps `angDist <= r_match` (`build.py:609`) with `R_MATCH_ARCSEC = 0.75`
  (`build.py:56`); the runner passes no `--r-match`, so 0.75 applies, same as the local manifests
  (`query_text: r_match_arcsec=0.75`). `evaluation/runner.py` has 0.75 only in report text (lines 46, 87, 1267),
  not in computation. The radius cannot change the result; a **CDS answer drift** can (catalogue version,
  `angDist` rounding near 0.75, pairs returned). Hence the parity check.
- Local reference (`data/interim/full_v0`, manifests + `dataset_report.json`): rows 2,044,246; class STAR 775,609,
  GALAXY 773,709, QSO 494,928; fold train 1,433,262, val 318,428, test 292,556; labels `file_sha256`
  `70a69da541fb9bae24e3cab2f236e836d40b30b6e943d2b6177979ddc8769213`; features `file_sha256`
  `aea60f3378dd27851e49bd658c4415c54115b50b015932b6bfed6b98d598ccb4`. Built with python 3.13.15 / pyarrow 26.0.0
  from 5+5 XMatch chunks. File sha256 depends on writer version/metadata, so it is **informational only**.
- `run_model` (`lgbm.py:449-451`) computes test metrics in memory; `train_lgbm_seeds.py` drops them (`KEPT`,
  `_has_test_key`). Nothing test-derived is written or printed by the seed script.
- `find_package` deletes `REPO` at start (`run_kaggle.py:100`), so seed artefacts must be restored on resume.

## Files
FILE: scripts/full_v0_parity.py  [create]
INTENT: compute and compare a row-data-free fingerprint of a full_v0 release.
EXPORTS: `fingerprint(outdir: Path) -> dict[str, object]`; `compare(ref: dict, got: dict) -> list[str]`
(names of differing fields, empty = match); `main(argv: list[str] | None = None) -> int` with subcommands
`reference --outdir D --out F` (local only) and `check --reference F --outdir D --report R`.
Exit: 0 match, 3 mismatch, 1 error (missing file, malformed reference, unsupported column type).
DEPENDS: stdlib, numpy, pyarrow (no astro_triage import, no network).
FINGERPRINT FIELDS: `schema: "full_v0_fingerprint/1"`, `rows`, `by_class`, `by_fold` (aggregate counts, already
public in `dataset_report.json`), `labels_schema`, `features_schema` (list of `"name:type"`),
`source_id_unique: bool`, `source_id_sha256` = sha256 of `np.sort(ids).astype("<i8").tobytes()`,
`labels_content_sha256`, `features_content_sha256`, `labels_file_sha256`, `features_file_sha256`.
CONTENT DIGEST (pseudocode): sort table by source_id; for each column in sorted name order feed
`name + b"\0"`, `is_null` as uint8 bytes, then values: integer/bool -> `fill_null(0)` as `<i8`; float ->
`<f8` with nulls and every NaN replaced by one canonical NaN; string/dictionary -> utf-8 of each value
(null -> "") + `b"\0"`; any other type -> exit 1 naming the column.
MATCH: every field equal except the two `*_file_sha256` (reported as `file_sha256_equal` true/false, never a
criterion); `source_id_unique` must be true on both sides.
INVARIANTS: output never contains a per-object value; report written temp+rename; reads only the two parquets.
ACCEPTANCE: `reference` on the local release reproduces the counts above; `check` exits 0 on a copy, 3 on each
mismatch kind in test 3. RISK: float columns rebuilt with another numpy/pyarrow may differ in the last bit (O4).

FILE: kaggle/full_v0_reference.json  [create; generated by the coder with `reference` on the local release]
INTENT: embedded expected fingerprint; counts and digests only, no row data. Committed; shipped by the package.

FILE: scripts/make_kaggle_package.py  [modify]
EXPORTS: `build(root, outdir, mode: dict[str, str] | None = None)`; CLI `--mode {phase1,seeds}` (default phase1)
and `--after-measure-one {stop,continue}` (required iff seeds).
INVARIANTS: phase1 output identical to today (no mode file). Seeds adds one in-memory entry
`kaggle/kaggle_mode.json` = `{"mode": "seeds", "after_measure_one": "<v>"}` (never written to the work tree);
a real file of that name in the repo -> PackageError. Seeds requires `kaggle/full_v0_reference.json`.

FILE: kaggle/run_kaggle.py  [modify]
EXPORTS: `read_mode() -> dict` (absent file -> `{"mode": "phase1"}`; unknown key/value -> fail);
`plan_stages(mode: dict) -> list[str]`; `remaining_fits(report: dict) -> dict[str, list[int]]`; last line becomes
`if __name__ == "__main__": main()` (the notebook `exec` runs with `__name__ == "__main__"`; tests can import).
PHASE1 PLAN (unchanged): pacote, pip, retomada, specobj, candidatos, xmatch, dataset, treino, avaliação, zip.
SEEDS PLAN: pacote, pip, retomada, specobj, candidatos, xmatch, dataset, paridade, retomada_seeds,
seeds_measure_one, [seeds_rest only if after_measure_one == "continue"], zip_seeds. No `train_lgbm.py`, no
`evaluate.py`. Each stage logs `[<stage>] start` and `[<stage>] done in <s>s`.
- paridade: subprocess `full_v0_parity.py check --reference REPO/kaggle/full_v0_reference.json --outdir
  DATASET_DIR --report WORKING/parity_report.json`; exit 3 -> log `[paridade] MISMATCH: <field>` per field,
  run zip_seeds, then fail (no training). Exit 1 -> same path. Exit 0 -> log `[paridade] match`.
- retomada_seeds (only after a match): copy into `DATASET_DIR/lgbm_seeds/` without overwriting, from input dirs
  `**/lgbm_seeds/` and from `astro_triage_outputs*.zip` members `lgbm_seeds/*`; log the count.
- seeds_measure_one: if `lgbm_full_s0` is in the report `fits`, skip and log its stored `wall_seconds`; else run
  `train_lgbm_seeds.py --outdir DATASET_DIR --measure-one`.
- seeds_rest: a fit is done iff its id is in report `fits`; call `--features full --seeds <csv of 1..4 not done>`
  and `--features noind --seeds <csv of 0..4 not done>`, skipping empty lists. Partial files without a report
  entry are left to the script, which refuses (exit 1) -> fail; the human decides.
- `WORKING/seeds_run.json`: mode, after_measure_one, per-stage seconds, `measure_one_wall_seconds` (from the
  report), fits done, fits skipped as restored.
- zip_seeds: members only `lgbm_seeds/**` (from DATASET_DIR), `parity_report.json`, `seeds_run.json`,
  `environment.json`, `run_log.txt`; refuse any arcname outside these or named `labels.parquet`/`features.parquet`;
  require `parity_report.json`. Cleanup keeps the zip, `run_log.txt` and `xmatch_full/` (Kaggle-side resume
  cache, not for download); deletes `repo/` so no full_v0 parquet stays in the output. Stages after paridade
  run in try/finally so zip_seeds also runs when a fit fails.
INVARIANTS: phase1 path calls the same commands with the same arguments as today; seeds mode never writes test
metrics or per-object labels to a file or the log.
RISK: Kaggle may not save `/kaggle/working` of a session that hits its time limit (not verified) -> resume
from that version may find nothing; `after_measure_one: stop` gives a saved checkpoint early.

## Outputs decision
Zip excludes full_v0 parquets: they hold per-object test labels, the local copy is the reference, and parity
proves the rebuild equal. Includes the seed prediction parquets (val+test `p_*`, no labels): the ADR 0006
section 5.2 evaluator needs val+test coverage, and `delta.json` is computed locally from val with local labels.

## Session budget (no invented numbers)
specObj download 6,741,023,040 bytes: time unknown. Candidates extraction: unknown. XMatch: 10 requests

## Acceptance tests (tester, pure local; `tests/test_full_v0_parity.py`, `tests/test_kaggle_seeds_mode.py`)
1. `plan_stages({"mode": "phase1"})` and absent mode file give the phase1 list; with stage functions and
   `run_stream` monkeypatched, phase1 `main()` records the same commands as the current code.
2. Seeds plan equals the list above for `stop` and `continue`; no recorded command contains `train_lgbm.py`
   or `evaluate.py`.
3. Parity on a small fixture release: exit 0 on identical copy (and on a re-written parquet with other file
   bytes); exit 3 with the field named for: rows, by_class, by_fold, one source_id swapped, one label changed,
   one feature value changed, column added/renamed; exit 1 on missing file / malformed reference.
4. Mismatch path: zip_seeds runs, zip has `parity_report.json` and no `lgbm_seeds/`, then SystemExit.
5. `remaining_fits` on reports with 0, 1 (s0) and 10 fits; restored fits are not passed to the script.
6. zip_seeds refuses `labels.parquet`; no zip member or `seeds_run.json` key contains "test" except the
   `by_fold.test` count in the parity report; seeds package has `kaggle/kaggle_mode.json`, phase1 does not.
